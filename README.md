# MyDrawer

一个轻量、独立的应用抽屉工具。首次启动自动载入全部已安装应用并按规则分类，无需替换桌面。独立重写，无广告、无统计、无内购。

**当前版本 2.9.14（`versionCode` 29）**。界面固定纯黑不透明底，详见 [CHANGELOG.md](CHANGELOG.md)。

## 功能

- **自动载入 + 自动分类**：首次启动按系统抽屉可见范围读取应用，用随包内置的分类规则自动归类（游戏 / 上网 / 影音 / 通讯 / 工具 / 设置 / 未分类）；完整应用清单与图标的**建立缓存放到后台**，不挡首屏。后续启动直接还原缓存、不再逐个读取图标；缓存采用原子写入，中途中断也不会留下坏缓存。安装 / 卸载 / 更新应用或切换系统语言会**即时自动刷新**，不会停留在旧图标或漏掉新应用。设置 →「程序列表」里有「重建应用列表缓存」入口，仅在显示异常时手动兜底。
- **纵列分类抽屉**：左侧竖排分类图标栏（略带冷灰蓝的深底 + 1dp 分界线，与应用区纯黑明显区分），彩色分类图标大小可独立调节（80%–240%，栏宽随图标自适应不被裁），应用图标大小可调 80%–200%，分类与应用文字可设置；支持左手模式（分类栏放右侧）。「全部」与「最常用」两个入口都可单独关闭，「最常用」默认排在分类栏最前。
- **分类管理**：分类栏底部「+」新建分类（同时选图标，名称框前实时显示已选图标，固定插在「未分类」之前），长按分类可重命名 / 换图标 / 拖动排序 / 删除；「未分类」始终是最后一项。长按分类 →「多选分类」可一次勾选多个分类并批量删除或移动。删除后其中应用归入「未分类」。自定义分类随配置备份一起保存。
- **分类嵌套**：长按分类 →「嵌套到其它分类」可把分类挂到另一分类下（自动防成环，可移回顶层）。嵌套分类不单独占分类栏，而在父分类内容里作为可点进的入口，分类栏更清爽；点进去后返回键（或左上角返回箭头）回到上一级分类。子分类默认排在父分类所有应用之前，设置 →「子分类位置」可改排后；子分类之间按分类排序规则排、手动排序时可在分类菜单 →「排序子分类」自由拖动；各分类内部应用仍按本分类规则排序，互不影响。
- **未分类自动显隐**：所有应用都已归类时「未分类」自动隐藏，出现未分类应用时自动出现；长按应用或在多选里「取消分类」即移入「未分类」。
- **自由拖拽排序**：按住分类 / 应用行右侧的加粗双横条，可一次拖到任意位置；分类内应用排序为独立单列对话框，不与分类菜单混在一起。
- **记住启动分类**：默认进入上次使用的分类，可在设置里改为每次固定进入某个分类。
- **多选批量操作**：右上角勾选图标或长按应用 →「多选」进入，跨分类勾选多个应用，可批量勾选所属分类（一个应用可同时归属多个分类）、批量取消分类或批量隐藏。
- **一个应用可属于多个分类**：长按应用 →「所属分类（可勾选多个）」，勾选加入、取消勾选移出；例如软件商店可同时挂在「系统程序」与「网络工具」下调用。「未分类」与具体分类互斥——勾选具体分类会自动取消未分类，勾选未分类则清空其它分类；全部取消也归入「未分类」。
- **深度定制**：长按应用可重命名 / 换图标（内置矢量图库 / 本机图库 / 应用原图标）/ 取消分类 / 发送到桌面 / 查看属性；分类内支持按名称 / 安装时间 / 使用频率 / 手动排序。应用列表上方的分类标题后面显示该分类当前的应用数量。
- **最常用分类**：在系统「使用情况访问权限」授权后，按最近 30 天本机真实使用频率排列；显示数量默认 10，可在设置里手动输入（上限为本机有使用记录的应用数）。未授权时回落到应用内启动次数。首次进入提示授权一次（可暂不），之后可在设置里开关并随时前往授权。
- **搜索**：按应用名 / 包名实时过滤，支持中文全拼与拼音首字母（如「微信」可用 weixin / wx 命中，基于 Android ICU，无需联网）；英文按单词前缀匹配，不会把 ser 之类子串的无关项翻出来。
- **隐藏应用 + 密码锁**：长按图标隐藏，多选也可批量隐藏；设置 →「管理隐藏应用」可多选恢复（也有单行「恢复」）；默认只列出系统抽屉里真实可见的程序（有桌面图标的），「显示系统应用」才列出系统跟踪、开关控制这类无入口的系统程序；设置 →「应用载入统计」会显示「已载入 X / 本机安装 Y」，可点开核对因无桌面入口而未列出的具体应用；「使用密码（管理隐藏应用）」可设置 / 修改 / 清除密码（只存加盐 SHA-256 摘要），设置后进入「管理隐藏应用」需先输入密码。
- **配置备份**：右上角软盘图标 = 导出，时钟图标 = 导入；开放 JSON 备份（分类覆盖、隐藏列表、排序、图标、外观），兼容原版备份数据，v1 旧备份仍可导入。
- **自动更新**：默认直连检测 GitHub Release（按版本号比较，不会把同版本误判为更新），可选公共反向代理下载升级；点击后**先完整下载安装包、再直接拉起系统安装器**，无需预先开启「安装未知应用」授权，系统安装界面返回后仍可用对话框里的「重新安装」一键续装而不必重新下载；不含本机代理。
- **自动检查更新**：设置 →「备份与更新」开关，默认关闭；开启时立即检查一次，之后每次进入应用每 24 小时最多一次，只有发现新版本才弹更新对话框；已是最新或网络失败都静默跳过。
- **调试日志**：设置 →「调试」开关，开启后记录启动、载入统计、卸载各路径结果、检查更新 / 下载安装、备份导入导出等关键链路，滚动保留最近 300 条并持久化；「查看调试日志」可复制、保存到系统**下载目录 `Download/MyDrawer/`**（Android 10+ 走 MediaStore，不需要存储权限）、清空，操作结果在对话框内即时提示。只存本机、不上传。

## 技术

- Kotlin + Jetpack Compose（Material 3），minSdk 26 / targetSdk 37
- `QUERY_ALL_PACKAGES` 读取全部应用；SAF 导出/导入备份，适配分区存储
- 权限：`QUERY_ALL_PACKAGES`（读取全部应用）、`INTERNET`（自动更新）、`REQUEST_INSTALL_PACKAGES`（拉起系统安装器）、`REQUEST_DELETE_PACKAGES`（ColorOS 15 拉起卸载器必需，缺了会静默失败）、`PACKAGE_USAGE_STATS`（「最常用」需用户手动授权）；日志导出走 MediaStore，不申请存储权限
- GitHub Actions 打 `vX.Y.Z` 标签触发 Release，产出 universal / arm64-v8a / armeabi-v7a 三个 APK + SHA256SUMS

## 构建

```bash
./gradlew assembleDebug       # 本地 debug 包
./gradlew testDebugUnitTest   # 单元测试
```

Release 由 CI 在打标签时构建，使用仓库内置的固定签名（`.github/signing/release.keystore.b64`），确保各版本签名一致、可原地覆盖升级。

**注意**：v1.0.0 / v2.0.0 使用过临时签名，与 v2.1.0 起的固定签名不同。若设备上已安装旧版，需先卸载旧版再安装 v2.1.0，之后的升级即可直接覆盖。升级前可用右上角软盘图标导出配置备份，装好后用时钟图标导入。
