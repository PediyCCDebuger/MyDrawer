# MyDrawer

一个轻量、独立的应用抽屉工具。首次启动自动载入全部已安装应用并按规则分类，无需替换桌面。独立重写，无广告、无统计、无内购。

**当前版本 2.5.0（`versionCode` 8）**。界面固定纯黑不透明底，详见 [CHANGELOG.md](CHANGELOG.md)。

## 功能

- **自动载入 + 自动分类**：首次启动读取全部应用，用随包内置的分类规则自动归类（游戏 / 上网 / 影音 / 通讯 / 工具 / 设置 / 未分类）。
- **纵列分类抽屉**：左侧竖排分类图标栏（略浅于纯黑的深色底），彩色分类图标大小可独立调节，分类与应用文字可设置；支持左手模式（分类栏放右侧）。「全部」与「最常用」两个入口都可单独关闭，「最常用」默认排在分类栏最前。
- **分类管理**：分类栏底部「+」新建分类，长按分类可重命名 / 换图标 / 拖动排序 / 删除；删除后其中应用归入「未分类」。自定义分类随配置备份一起保存。
- **未分类自动显隐**：所有应用都已归类时「未分类」自动隐藏，出现未分类应用时自动出现；长按应用或在多选里「取消分类」即移入「未分类」。
- **自由拖拽排序**：分类栏顺序、手动排序分类内的应用顺序都支持长按拖动自由调整。
- **记住启动分类**：默认进入上次使用的分类，可在设置里改为每次固定进入某个分类。
- **多选批量操作**：跨分类勾选多个应用，可一键移动到目标分类或批量取消分类。
- **深度定制**：长按应用可重命名 / 换图标（内置矢量图库 / 本机图库 / 应用原图标）/ 取消分类 / 查看属性；分类内支持按名称 / 安装时间 / 使用频率 / 手动排序。
- **最常用分类**：在系统「使用情况访问权限」授权后，按最近 30 天本机真实使用频率排前 10；未授权时回落到应用内启动次数。首次进入提示授权一次（可暂不），之后可在设置里开关并随时前往授权。
- **搜索**：按应用名或包名实时过滤。
- **隐藏应用**：长按图标隐藏，设置里可显示系统应用。
- **配置备份**：右上角软盘图标 = 导出，时钟图标 = 导入；开放 JSON 备份（分类覆盖、隐藏列表、排序、图标、外观），兼容原版备份数据，v1 旧备份仍可导入。
- **自动更新**：默认直连检测 GitHub Release（按版本号比较，不会把同版本误判为更新），可选公共反向代理下载升级；点击后**先完整下载安装包、再直接拉起系统安装器**，无需预先开启「安装未知应用」授权，系统安装界面返回后仍可用对话框里的「重新安装」一键续装而不必重新下载；不含本机代理。

## 技术

- Kotlin + Jetpack Compose（Material 3），minSdk 26 / targetSdk 37
- `QUERY_ALL_PACKAGES` 读取全部应用；SAF 导出/导入备份，适配分区存储
- 仅申请 `QUERY_ALL_PACKAGES`、`INTERNET`（自动更新）与 `REQUEST_INSTALL_PACKAGES`（拉起系统安装器），不申请危险权限
- GitHub Actions 打 `vX.Y.Z` 标签触发 Release，产出 universal / arm64-v8a / armeabi-v7a 三个 APK + SHA256SUMS

## 构建

```bash
./gradlew assembleDebug       # 本地 debug 包
./gradlew testDebugUnitTest   # 单元测试
```

Release 由 CI 在打标签时构建，使用仓库内置的固定签名（`.github/signing/release.keystore.b64`），确保各版本签名一致、可原地覆盖升级。

**注意**：v1.0.0 / v2.0.0 使用过临时签名，与 v2.1.0 起的固定签名不同。若设备上已安装旧版，需先卸载旧版再安装 v2.1.0，之后的升级即可直接覆盖。升级前可用右上角软盘图标导出配置备份，装好后用时钟图标导入。
